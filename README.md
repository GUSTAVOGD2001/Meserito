# Meserito

Meserito es una aplicación de escritorio para la administración de un restaurante.

## Requisitos

```bash
python -m venv .venv
source .venv/bin/activate  # En Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
```

## Inicialización

```bash
python -m app.main
```

## Notas para Windows

Si usas PowerShell y `conda` no es reconocido, ejecuta:

```powershell
& "C:\\ProgramData\\miniconda3\\shell\\condabin\\conda-hook.ps1"
conda activate SoftwareSpiral
```

O bien utiliza un entorno virtual de Python puro.
